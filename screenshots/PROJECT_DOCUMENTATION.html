About This Project

This is a complete, production-ready business website built for Vastraa — Luxury Indian Ethnic Wear, an artisanal heritage fashion label celebrating millenary Indian textile weaving clusters. The website incorporates 18 fully integrated pages engineered with semantic HTML5, CSS Grid, Flexbox, Dart Sass (SCSS 7-1 pattern), and framework-free Vanilla JavaScript.

Key Features Included:

  • Multi-Page Architecture: Homepage (index.html), Heritage (about.html), Bespoke Services (services.html), Concierge (contact.html), Collections (shop.html), Product Detail (product.html), Bag (cart.html), Checkout (checkout.html), and Admin Suite (admin.html).
  • Interactive E-Commerce State Engine: Integer-paise currency math (preventing JavaScript float errors), dynamic quantity steppers, live privilege vouchers (VASTRAA10), and free delivery thresholds.
  • Accessible Form Validation: Modular engine (js/form-validation.js) validating emails, 10-digit Indian mobile numbers with +91 prefix, and 6-digit Indian PIN postal codes.
  • Atelier Executive Suite: Real-time inventory editing, stock level auto-saving, order fulfillment slips, and printable GST tax invoices without browser thread locking.
  • 5-Stage Order Tracking: Realistic simulated courier tracker verifying milestone progress for patron orders.

What I Learned

  • HTML5 Structure: Mastered the use of semantic landmark tags (<header>, <nav>, <main>, <section>, <article>, <aside>, <footer>, <dialog>), establishing a clean accessibility tree with ARIA landmarks and structured JSON-LD microdata.
  • CSS Layouts (Grid & Flexbox): Mastered 2D CSS Grid for macro-layouts (product matrices, editorial splits, responsive card galleries) and 1D Flexbox for micro-alignments (navigation bars, action clusters, badges, quantity steppers).
  • SASS/SCSS Organization: Adopted the modular 7-1 SASS architecture to manage variables, color tokens (Imperial Burgundy, Warm Ivory, Zari Gold), typography scales, and responsive mixins.
  • Modern JavaScript: Developed interactive features using modern native ES modules (import/export), focus-trapped dialogs, touch-friendly mobile drawers, and smooth-scrolling navigation.
  • Accessibility (A11y): Built with WCAG 2.2 AA compliance from day one, including alt text on all imagery, high color contrast (>4.5:1), visible focus rings, and skip-to-content links.
  • Cross-Browser Testing: Verified flawless rendering with zero horizontal overflow across Chrome, Firefox, Edge, and Safari at 1440px desktop, 1024px tablet, and 375px mobile viewports.

Challenges & Solutions

Challenge 1: Making Complex 2D Layouts Responsive Without Layout Shifts

Solution: Designed dedicated layout subsystems (css/layout.css and css/responsive.css) using CSS Grid repeat(auto-fill, minmax(280px, 1fr)) on desktop, collapsing smoothly to 2 columns on tablet and 1 column on mobile via mobile-first media queries and overflow-x: hidden safeguards.

Challenge 2: Dynamic Stock & Quantity State Synchronization Without Frameworks

Solution: Engineered an event-driven state architecture using integer paise (1 INR = 100 paise) to eliminate JavaScript floating-point rounding errors across vouchers and line items, persisting to localStorage with corrupted-data fallback boundaries.

Challenge 3: Accessible, Multi-Field Form Validation with Real-Time Feedback

Solution: Built a modular, standalone form validation engine (js/form-validation.js) that attaches to forms, validating required inputs, emails, Indian phone numbers (/^[6-9]\d{9}$/), and PIN codes (/^[1-9][0-9]{5}$/) with ARIA live region error announcements.

Challenge 4: Preventing Browser Freezing in Admin Slip/Invoice Modal

Solution: Refactored the invoice generation to use native <dialog> controllers, decoupling DOM rendering from print triggers and providing accessible close handlers that properly restore focus.

Technical Details (Algorithms, Data Structures & Architecture)

The application implements several specialized algorithms and data structures to ensure precision, responsiveness, and resilience:

  • Integer-Paise Monetary Math: Currency calculations are handled exclusively in integer paise (1 INR = 100 paise) rather than floating-point decimals, completely preventing JavaScript binary rounding errors across voucher discounts and GST tax calculations.
  • Validation Regular Expressions: Standardized validation algorithms for email syntax, 10-digit Indian mobile numbers (/^[6-9]\d{9}$/ with optional +91 prefix), and 6-digit Indian postal PIN codes (/^[1-9][0-9]{5}$/) encapsulated in js/form-validation.js.
  • LocalStorage Schema & Error Boundary: Normalized key-value data structures with defensive try/catch error boundaries that gracefully catch corrupted data or quota exhaustion without crashing the application.
  • Modular Dart Sass 7-1 Architecture: Separation of design tokens (variables), mixins, reset rules, UI components, and page layouts, compiling to clean, minified production CSS.

Component Architecture & Data Flow Diagram

The application follows a predictable, unidirectional event-driven architecture:

[User Interaction] (Click "Add to Bag", Filter, or Step Quantity)
       │
       ▼
[DOM Event Listener] (Vanilla JS Module: cart.js, filters.js)
       │
       ▼
[Validation & Calculation] (Integer-paise math, stock boundary check)
       │
       ▼
[State Mutation & Persistence] (LocalStorage with JSON schema error boundary)
       │
       ▼
[Dispatched CustomEvent] ("vastraa:cart-updated", "vastraa:stock-changed")
       │
       ▼
[UI Subscribers Update] (Badge counters, slide-out drawer, ARIA live region)
